# Информационные системы. Лабораторная работа № 1

Вариант 40268893.

Хлопцов СД

Java 21, Maven, Spring Boot 3, Spring MVC, EclipseLink, PostgreSQL. 

Интерфейс - HTML, CSS и JavaScript

Приложение открывается без входа. Для параллельной работы достаточно открыть его в нескольких вкладках. Изменения передаются через `/ws/changes` после фиксации транзакции; после переподключения вкладка перечитывает данные.

Открытая форма сохраняет введённые значения при чужих изменениях. Неизменённые поля обновляются с уведомлением, при конфликте одного поля остаётся локальный ввод. Удалённый маршрут можно создать заново кнопкой «Сохранить»: недостающие координаты и локации создаются вместе с ним в одной транзакции. ID новых объектов отличаются от удалённых. «Отмена» закрывает форму без восстановления. Черновик живёт только в памяти открытой страницы и теряется при её перезагрузке; cookies и localStorage для работы не нужны.

Проверки: `mvn verify` запускает интеграционные тесты на временной PostgreSQL, `node --test src/test/js/collaboration.test.cjs` проверяет работу открытых форм и обработку уведомлений.
